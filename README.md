## Project Objective
The owner wants to create an annual sales report from this data. So, that the owner can understand their customer and grow more sales next year.
## Dataset Used
- <a href="https://www.kaggle.com/datasets/shantanugarg274/sales-dataset">Sales Dataset<a/>
## Question (KPIs)
- Total Profit earned by the seller on each category of product in every state.
- Total number of each category of product sold in each state.
- Total profit earned by seller from each state.
## Process
- Verify data for any duplication on dataset.
- Verify data for any missing values and anomalies, and sort out of them.
- Made sure that data is consistent and clean with respect to data type, date formate and values used.
- Created pivot tables according to the question asked.

## Final Conclusion:
The Sales Trend Visualization project successfully analyzed the annual sales data using Excel and Power BI. After cleaning and validating the dataset, dashboards were created to visualize profit, sales quantity, and state-wise performance.

The analysis helped identify the most profitable product categories and the states generating the highest sales and profit. These insights can help the business owner make better decisions regarding inventory, marketing, and sales strategies. Overall, the dashboard provides a clear understanding of sales performance and supports data-driven planning for increasing future sales and profitability.
